## 2025-02-18 - Nested filter loops in React render methods
**Learning:** Found several components where `array.filter(condition).length` was being called multiple times inside `useMemo` hooks or `.map` iterations during render. Specifically in `AIBrainModule.jsx` and `ReportsModule.jsx`, the app iterated over the main collections (like `P.tickets`) multiple times to extract different counts and groupings.
**Action:** Replaced these `O(N * M)` operations by combining the passes into a single `.reduce()` step. Instead of running `.filter()` sequentially for 'open', 'resolved', and 'critical' tickets, we iterate once and collect or count them simultaneously using an accumulator object. This minimizes O(N) loops.
